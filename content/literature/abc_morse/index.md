J'adore le Morse. C'est un code télégraphique(donc qui utilise un télégraphe),
avec des points et des virgules. Voici un exemple du code Morse: 
--/---/.-./..././/.-.-.-
Ce morceau veut dire "MORSE." Oui, même le point(.-.-.-)! C'est pour cela que c'est très utile d'utiliser le code Morse; le seul défaut, c'est qu'il est un petit peu trop long...😅

Il y a beaucoup d'astuces pour apprendre le morse... la première: apprendre par cœur! Moi, j'ai appris avec une astuce: les syllabes...😅
